# Try it in this project

Picking a base color and a rule in step 1 makes a complete theme you can try or save straight away. Steps 2 to 5 are optional fine-tuning.

**Try in VS Code** shows your design as GigglyBits Dark (Lab):

- With a folder open, it changes only that project. Other windows keep their own theme.
- With no folder open, it changes every window that doesn't set a theme of its own.

There is one Lab theme, so a Try also changes any other window that is showing GigglyBits Dark (Lab).

To keep a design for a project, use **Save theme**, then **Use in this project** on the saved theme. A later Try in that project switches it to the Lab theme; the Try message's **Back** button puts the saved theme back.
