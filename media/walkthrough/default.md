# Choose your default theme

Every window that doesn't set its own theme uses your default theme. A project that you gave a theme with **Use in this project** keeps it.

The Lab's first step says which theme this window shows, where that comes from, and which theme new windows get. **Change default** lists your installed themes and makes the one you pick the default.

If colors in your user settings aren't tied to any theme, they override every theme, GigglyBits ones included. The Lab names them in its first step and offers to remove them.

The **Set Color Theme** button on the extension's page lists GigglyBits Dark (Lab) and GigglyBits Theme 1 to 12. The twelve slots look like the starter theme until you save designs into them.
