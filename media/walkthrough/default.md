# Choose your default theme

Every window that doesn't set its own theme uses your default theme. A project that you gave a theme with **Use in this project** keeps it.

The Lab's first step says which theme this window shows, where that comes from, and which theme new windows get. **Change default** lists your installed themes and makes the one you pick the default.

If colors in your user settings aren't tied to any theme, they change every theme wherever the theme doesn't set that color itself. The Lab names them in its first step and offers to remove them.

The **Set Color Theme** button on the extension's page lists GigglyBits Dark (Lab). Themes you save appear in **Preferences: Color Theme** as `GigglyBits: <name>`, from a small extension GigglyBits generates for them, GigglyBits Saved Themes.
