# Open the Theme Lab

The Theme Lab is where you design a theme. Open it with the button on the left, or run **GigglyBits: Open Theme Lab** from the Command Palette.

It opens a second window, the Theme Preview, which draws a whole VS Code window and every kind of widget in your colors. It follows each change as you make it. Click any part of the preview to change just that color.

You don't need the **Set Color Theme** button on the extension's page to get started. That list shows GigglyBits Dark (Lab) and GigglyBits Theme 1 to 12, and the twelve slots only hold your designs once you save them.
